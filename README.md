# RentincreaseSF3

Source-verified research dashboard on reasonable, lawful rent increases for two rent-controlled
units in San Francisco (built 1940), organized for executive review.

**Live site (GitHub Pages):** https://kanlerxz87-cyber.github.io/RentincreaseSF3/

## Contents

| Page | Purpose |
|---|---|
| `index.html` | Landing dashboard — key figures and navigation |
| `executive-summary.html` | Executive summary of important details |
| `units.html` | Anonymized unit register (dates & amounts only, no personal data) |
| `allowable-increases.html` | Official Rent Board rate history, banking rules, worked calculations |
| `procedures.html` | Correct tenant-notice procedure and recognized reasons for increases |
| `legal-framework.html` | Local / state / federal law with citations |
| `market-practices.html` | Corporate vs individual landlord practices (official findings only) |
| `analysis.html` | Findings, one-unit-vs-both analysis, tenant-lawyer review checklist |
| `flagged.html` | Flagged for Review — unverified items and assumptions |
| `sources.html` | Full source register with verification dates |
| `COORDINATION.md` | Multi-session task board, sources/verification log, merge & deploy record |

## Verification policy

- Every table row links to an official government source (sf.gov / California Legislature /
  U.S. GPO / CRS).
- Values that cannot be confirmed from an official source are left **blank** and flagged on the
  Flagged for Review page — never inferred.
- No personal information (names, initials, addresses, ZIP) is stored anywhere in this repository.

## Disclaimer

Research documentation only — not legal advice. Confirm coverage and figures with the SF Rent
