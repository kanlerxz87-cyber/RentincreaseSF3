# RentincreaseSF3

**Executive analysis of lawful, reasonable, and normal rental increases** for a rent-controlled,
two-unit residential building constructed in **1940** in San Francisco's Outer Sunset (ZIP 94122).

- **Live site (GitHub Pages):** https://kanlerxz87-cyber.github.io/RentincreaseSF3/
- **Scope:** SF Rent Ordinance (Ch. 37) · California AB 1482 / Civil Code §827 / Costa-Hawkins ·
  federal Fair Housing Act · corporate vs. individual landlord practice · notice mechanics ·
  discrimination analysis · flagged-for-review register.
- **Privacy:** All personal information is anonymized on the site. Names and initials of occupants
  are never published; dates and dollar amounts are preserved exactly as provided.
- **Source policy:** Every table row cites an official source (sf.gov, leginfo.legislature.ca.gov,
  hud.gov, calcivilrights.ca.gov) or is explicitly flagged unverified on the site's
  "Flagged for Review" page — never filled with a guess.
- **Not legal advice.** Consult the SF Rent Board (415-252-4600) and a California attorney before acting.
