# Rent Review SF

A static, privacy-conscious research dashboard for GitHub Pages. Open `index.html` locally or serve the repository root with any static server. The public site intentionally omits names, initials and street address; dates and amounts are user-reported and may still be identifying. The site is educational, not legal advice. See the Flagged for Review page before acting.

No build dependencies are required. Official source links are provided for each table row; they establish the governing guidance, not private tenancy facts or legal clearance.
