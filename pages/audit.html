What was built

Deliverable
Path Purpose
Calculation engine tools/rentcalc.py The single source of truth for every number published. Implements rules R1-R8, each tied to an official source, and holds the complete official allowable-increase table from April 1, 1982 to February 28, 2027, the security-deposit interest rates and the CPI series.
Verification report tools/calc.py Asserts the engine reproduces all four official Rent Board worked examples exactly before writing any output, then prints every published number and writes data/_calc.json. Exits non-zero on any failure.
Source register tools/content.py All 40 sources with publisher, URL, what each verifies and how it was checked.
Flag register tools/content.py All 15 flags with severity, detail and action taken.
Site generator tools/build_site.py Renders every page from the verified data only.
Link checker tools/check_links.py Verifies every internal link resolves to a real file and every external link returns HTTP 200.
Site index.html and pages/*.html Dashboard landing page plus 15 subpages organised by category. No CDN, no external fonts, no build step at serve time.
Machine-readable data data/*.csv, data/*.json The official rate history, the source register, the flag register and every computed scenario, so the published figures can be audited outside the HTML.
Documentation EXECUTIVE_SUMMARY.md, docs/law/*.md, docs/analysis/*.md, docs/audit/repo-audit.md, docs/verification/*.md The same findings in Markdown for review without a browser.
Coordination log COORDINATION.md Task board, source register, flag register and change log.

Verification performed

Check
Method Result
Every published percentage Traced to SF Rent Board document 571 and cross-checked against the Current Rates page. Matched
Every published dollar amount Recomputed by the engine; the engine is asserted against four official worked examples ($1,047.00, $1,033.00, $1,387.10, $1,016.00) before it writes anything. 4 of 4 matched exactly
Every notice deadline Computed from Civ. Code Sec. 827(b) plus the sf.gov 5-day mailing rule. Matched
Every statutory quotation Read from the California Legislative Information code display or from the official compiled ordinance and Rules and Regulations PDF published on sf.gov. Matched
Third-party claims Read, compared against official sources, and excluded. Three material errors found and recorded as flags F2 and F3. Zero third-party values used
Internal links Checked by tools/check_links.py against the filesystem. See the CI record
External links HTTP status checked by tools/check_links.py in CI on every push. See the CI record
Personal information Searched every generated page for names and addresses. None published
Unverifiable values Left blank and listed on the flag register rather than estimated. 13 blanks, all documented

Reproducibility

python3 tools/calc.py         # self-tests against the four official worked examples; writes data/_calc.json
python3 tools/build_site.py   # regenerates index.html, pages/*.html and data/*.csv from verified data only
python3 tools/check_links.py  # verifies every link (use --offline where the network is unavailable)

No third-party packages are required. The site uses no CDN, no external font and no runtime network call, so it renders identically offline and on GitHub Pages.
